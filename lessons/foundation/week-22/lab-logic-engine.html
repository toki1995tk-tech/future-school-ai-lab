Миссия 1

AI reaction
Если введено yes, AI хвалит. Во всех остальных случаях предлагает попробовать ещё раз.
Input: yes → Output: Молодец!
Input: no → Output: Попробуй ещё раз

🐞 Найди логическую ошибку

Debug
Плохой код:
level = input()
if level == 'expert':
    print('Простой пример')
elif level == 'beginner':
    print('Сложная задача')
else:
    print('Обычное объяснение')
Input: beginner → Output: Простой пример
Input: expert → Output: Сложная задача

⚙️ AI учитывает настроение и уровень

Decision engine

beginner + tired → Начнём с лёгкой задачи
beginner + normal → Объясню простыми словами
middle + normal → Покажу пример и дам задачу
advanced + normal → Дам челлендж
